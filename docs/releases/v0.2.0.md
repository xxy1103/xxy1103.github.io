# v0.2.0 Release Notes

Release date: 2026-07-14

## Highlights

- Upgraded the theme runtime from Astro 5 to Astro 6.4.8.
- Upgraded the official MDX integration to the Astro 6-compatible v5 release.
- Migrated custom Markdown processing to `markdown.processor` with the unified remark/rehype pipeline.
- Adopted Zod 4 through the `astro/zod` entry point while preserving the existing Frontmatter schema.
- Set Node.js 22.12.0 and npm 9.6.5 as the minimum supported toolchain.
- Kept Astro v6's native GitHub-compatible Markdown heading IDs.
- Standardized the official demo and canonical URL on `https://template.ulna520.top`.

## Upgrade Notes

- Existing custom links to headings that end in special characters may need to adopt Astro v6's new trailing-hyphen IDs.
- Run `npm ci`, `npm run check`, and `npm run build` with Node.js 22.12.0 or newer.
- Image optimization remains an explicit command and is not run as part of the normal build.

## Verification Checklist

- `npm ci`
- `npm run check`
- `npm run build`
- `npm run optimize:images:dry-run`
- Verify the article table of contents, search, theme switching, and View Transitions in the browser.
